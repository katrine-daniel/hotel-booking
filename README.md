# Hotel Booking Website

A multi-page hotel booking site with a destination page for Goa, a property page and a sign-in / sign-up screen.

**Live demo:** https://katrine-daniel.github.io/hotel-booking/

## Features

- Booking search form on the home page
- Rooms, services, gallery and reviews sections
- Video hero on the Goa page
- Destination page (`goa.html`) and property page (`treebo.html`)
- Animated login / signup form (`login/login.html`)
- Testimonials and FAQ

## Tech stack

HTML5, CSS3, JavaScript

## Structure

```
index.html      Home
goa.html        Goa packages
treebo.html     Property page
login/          Sign in / sign up
style.css, script.js
images/
```

## Run locally

No build step. Clone the repo and open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
